## Clotho semantic-E2E baseline

Read operations are available: World, Canon and bounded Event search returned the
served revision and World-owned Event IDs. For example, searching `조선` returned
`조선 건국·태조 즉위` (`…0104`) and `국호 조선 사용` (`…0105`) with their Canon
memberships.

The connected Clotho exposes `change.validate` and `change.commit`; PR-0 did not
write. Its cached tool description says string `0.3.0`, but the actual server
accepts numeric contracts 4/3/2. A read-only numeric-v4 Canon creation probe
returned `valid=true`, `source_revision=1` and a plan digest; it was **not committed**.
This confirms current-contract validation through the actual connection without
changing the schema, semantics or authority. No claim of commit availability is
made from validation alone.

The connected actor is scoped to the existing public synthetic Joseon World.
PR-B must use public/synthetic authoring within that authorized World or obtain
explicit authority for a separate World; it must not silently expand grants or
reset the existing dataset. The earlier blanket demand for a dedicated World was
an execution assumption, not an IP-004 requirement. The required coarse creation,
three refinements and Publication/UI readback remain unchanged.
