## 수정한 동작

기존 화면에서 실제 WebKit 휠 입력을 재현하니, 지도 확대가 바뀌는 동시에 페이지 스크롤 위치가 368에서 608로 이동했다. 지도의 휠 처리에서 브라우저 기본 스크롤을 취소하지 않은 것이 원인이다.

지도 안의 휠 입력은 기본 페이지 스크롤을 취소한 뒤 지도 확대에만 반영한다. 지도 안에서 시작한 터치는 지도 이동에 사용하며, HTML 지도 영역의 `touch-action`과 그 영역에만 붙인 취소 가능한 터치 처리로 페이지 스크롤 전파를 막는다. 지도 밖의 페이지 스크롤은 그대로 사용할 수 있다. 문서 전체에 스크롤 잠금을 걸지 않는다.

제목·버튼·설명·오류 안내·접근성 이름과 연습 자료의 표시 이름을 한국어로 바꿨다. A는 ‘기준 화면’, B는 ‘바꾼 화면’이다. 각 값의 설명은 숫자를 키우거나 줄이면 화면에서 무엇이 달라지는지 알려준다. 기술 식별자와 자료 확인값은 ‘실험 정보 자세히’ 안에 두었다. 실제 역사 제목과 저장 파일의 원본 자료·키·버전·수치는 바꾸지 않았다.

## 사용 순서

1. ‘자세히 볼 사건 선택’에서 살펴볼 사건을 고른다.
2. ‘지금 B를 비교 기준 A로 저장’을 누른다.
3. ‘B의 묶음 사건 표시 조절’ 또는 ‘B의 사건 배치 방식’에서 값을 하나씩 바꾼다.
4. 지도 안을 끌어 위치를 바꾸고, 가로 또는 시간 방향 확대 버튼으로 두 그림을 함께 비교한다. 페이지를 내릴 때는 지도 밖을 쓸어 올린다.
5. 다시 보고 싶은 결과는 ‘실험 저장·다시 열기’에서 기기에 저장하거나 파일로 내보낸다.

‘묶음 사건’은 여러 구성 사건으로 이루어진 사건이다. ‘사건 모음’은 함께 볼 사건을 선택한 목록이다. 하나의 사건이 여러 모음에 속할 수 있으며, 모음을 끄고 켜는 것은 보이기만 바꾼다.

## 검증 범위

기존 고정 자료 복원, 같은 위치의 A/B 비교, 사건 모음 표시 선택, 기기 안에서의 배치 재계산 검증을 유지한다. 휠 조작 중 페이지 위치 유지와 지도 밖 스크롤, 터치 처리 범위를 추가로 검사한다. 자동화한 모바일 WebKit은 iPhone 14 모사 환경이며 실제 iPhone 17 Safari/PWA 사용 확인을 대신하지 않는다.

기존 4개와 새 입력 격리 2개를 합친 영구 Lab 브라우저 검사 6개가 모두 통과했다. 조절 중 추가 읽기·쓰기 요청 0, 저장 파일 왕복 복원, 같은 화면 위치의 A/B, 화면에 고정한 모바일 비교도 유지됐다.

이 checkout의 단위 검사 675개(기존 조건부 생략 2개), 전체 형식·정적 검사·타입 검사, 의존 경계 검사와 운영 빌드가 통과했다. Desktop WebKit의 실제 휠 입력으로 지도 안 페이지 이동 0과 지도 밖 페이지 이동을 확인했다. 모바일 WebKit은 실제 터치 시작·종료와 합성 이동의 결합 검사이며, 실제 손가락 이동을 완전히 재현했다고 주장하지 않는다. 별도 Chromium 모바일 모사에서는 브라우저의 실제 터치 입력 경로로 지도 이동 중 페이지 이동 0, 지도 두 손가락 조작 후 페이지 확대율 1 유지, 지도 밖 쓸기 후 페이지 215픽셀 이동을 확인했다. 두 모바일 검증 모두 실제 iPhone 기기 검증과 구분한다.
