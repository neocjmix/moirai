# CON-007 — 데이터 주권과 지속성

## CON-007.1 사용자 소유

사용자가 작성한 세계 데이터는 사용자에게 귀속된다.

## CON-007.2 제품 독립성

특정 LLM, 스킬 버전, 공개 UI 또는 호스팅 사업자가 사라져도 세계의 의미를 보존할 수 있어야 한다.

## CON-007.3 의미 보존

이동과 보존의 대상은 화면에 표시된 결과만이 아니라 세계를 재구성할 수 있는 의미 있는 원본이어야 한다.

## CON-007.4 장기 접근성

시스템이 발전하더라도 기존 세계를 읽고 이전할 수 있어야 한다.
