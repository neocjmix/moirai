비교를 읽는 방법

색은 Collection 소속입니다. 검은 점은 세 Collection이 공유하는 동일한 하나의 Event입니다. 각 그림에서 같은 Event ID를 사용하며 소속별로 Event를 복제하지 않습니다. 점을 누르면 소속을 확인할 수 있습니다.

처음에는 가로 축을 같은 축척으로 보여줍니다. 위 버튼으로 개별 확대를 선택할 수 있습니다. 축척 전환은 화면 표시만 바꾸고 Event 좌표를 재계산하지 않습니다.

이 실험이 보여주는 것

기존 배치와 결정적 시간 슬롯은 Collection 소속을 입력으로 받지 않으므로 이 사례에서 Collection별 영역을 만들지 못합니다. 세 번째 비교군은 전용 Event의 중심을 미리 구분했을 때의 효과를 보여줍니다. 자동 중심 배치나 계층 배치가 최선임을 증명하는 결과는 아닙니다.

연구용 비교군의 한계

세 번째 배치는 중심을 미리 지정했습니다. 자동 중심 탐색, 중첩 Collection, 공유 Composite Event, 실제 hull·운영 렌더러는 검증하지 않았습니다. 공유 Event는 같은 시점의 Collection B Event와 좌표가 겹칩니다. 점선 원은 공유 Event를 찾기 위한 표시이며 Collection hull이 아닙니다.

이 그림은 실제 중국사·한국사·일본사 데이터의 재현이 아닌 합성 fixture입니다. 각 Collection에 기본 40개 Event를 배정한 뒤 하나에 다른 두 Collection 소속을 추가했습니다. Moirai 운영 코드와 canonical 데이터에는 적용하지 않았습니다.
