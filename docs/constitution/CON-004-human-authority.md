# CON-004 — 인간의 최종 권위

## CON-004.1 최종 통제권

LLM은 Moirai의 주된 작성자이지만 세계와 공개 상태에 대한 최종 통제권은 인간에게 있다.

## CON-004.2 확인 가능성

LLM이 작성하거나 수정해 공개된 결과는 인간이 이해하고 확인할 수 있어야 한다.

## CON-004.3 작성 유래의 구분

원자료에 존재하는 내용, LLM의 추론과 시스템이 계산한 해석을 서로 구분할 수 있어야 한다.

## CON-004.4 정정과 철회

인간은 내부 저장 구조를 직접 이해하거나 편집하지 않고도 공개된 세계 내용을 정정하거나 철회할 수 있어야 한다.

## CON-004.5 자동 출판의 투명성

1차 구현에서 Clotho를 통해 성공적으로 반영된 세계 내용에는 별도로 관리되는 비공개 중간 상태가 없으며 현재 Publication의 내용이 된다. 인간은 이 기본 동작을 알고 있어야 하며, LLM 작업 과정이나 시스템 내부 정보가 세계 내용으로 오인되어 공개되어서는 안 된다. 이 원칙은 Atropos가 변경을 제공하기까지의 시간에 관한 SLA를 규정하지 않는다.
