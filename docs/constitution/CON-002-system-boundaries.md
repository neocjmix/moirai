# CON-002 — 세 시스템과 책임 경계

## CON-002.1 Clotho

Clotho는 사용자와 에이전트가 기존 세계를 이해하고 새로운 내용을 작성하거나 기존 내용을 수정하는 인증된 운영 인터페이스 전체를 소유한다. 호출 주체의 인증, 작업에 필요한 맥락 구성, 탐색·작성 수단과 오류 회복 경험은 Clotho의 책임이다. 1차 구현에서 성공적으로 반영된 세계 내용은 Atropos의 현재 공개 상태에 자동으로 이어진다.

## CON-002.2 Lachesis

Lachesis는 각 Canon 안에서 성립하는 세계의 사실과 운영 정보를 보존·검증·관리하고 Clotho와 Atropos에 신뢰할 수 있는 기능을 제공하는 비공개 관리 시스템이다. 정본 조회와 변경의 최종 인가, 세계 불변식, 원자적 변경과 이력의 권위는 Lachesis에 있다. 사용자와 에이전트의 운영상 접근은 Clotho를 통한다.

## CON-002.3 Atropos

Atropos는 출판된 세계를 독자가 탐색하고 이해할 수 있게 하는 유일한 공개 사용자 서비스이자 출판 시스템이다.

## CON-002.4 이름의 비규범성

Clotho, Lachesis, Atropos라는 이름은 시스템을 기억하고 구분하기 위한 이름이다. 신화적 의미는 기능, 내부 구조 또는 향후 아키텍처를 제한하지 않는다.

## CON-002.5 경계 원칙

각 시스템의 내부 구현은 바뀔 수 있지만 최상위 책임의 소유권은 명시적이어야 한다. 동일한 책임을 여러 시스템이 서로 다른 규칙으로 중복 소유해서는 안 된다. 출판 생성, 이관, 백업과 복구 등 제한된 내부 운영 경로는 Clotho를 경유하지 않을 수 있으나 각자의 권한과 정본 변경 규칙을 지킨다. Atropos의 독자 접근은 출판된 결과를 통해 이루어진다.
