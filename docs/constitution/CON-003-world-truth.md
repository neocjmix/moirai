# CON-003 — Canon과 해석적 지식 범위

## CON-003.1 사건 중심 세계

세계의 내용은 사건과 사건 사이의 관계를 중심으로 표현한다.

## CON-003.2 Canon의 의미

Canon은 하나의 World 안에서 특정 범위의 세계 지식을 함께 다루기 위해 명명되고 지속적으로 관리되는 해석적 지식 범위다. Canon은 curated body of world knowledge를 식별하지만 authority, exclusivity, completeness, consistency 또는 objective truth를 함의하지 않는다.

## CON-003.3 Canon의 overlap과 비권위성

World는 하나 이상의 Canon을 포함할 수 있다. Canon들은 서로 overlap할 수 있고 하나의 Event가 같은 World의 여러 Canon에 참여할 수 있다. Canon이 하나뿐이어도 특별한 truth semantics가 생기지 않는다. Moirai는 어느 Canon도 정본·기본·공식·우위 또는 더 완전한 Canon으로 채택하지 않는다.

## CON-003.4 Event identity와 membership

Event는 Canon이 아니라 World에 속하는 identity를 가진다. 모든 active persisted Event는 같은 World의 Canon 하나 이상에 참여해야 하며, Canon membership을 표현하기 위해 Event identity를 복제하지 않는다. membership이 없는 active Event와 cross-World membership은 허용하지 않는다.

## CON-003.5 차이와 상충의 보존

여러 Canon은 같은 Event를 공유하면서 서로 다른 관계나 서술 맥락을 가질 수 있다. Canon 사이 또는 한 Canon 안의 내용이 상충한다는 이유만으로 하나로 병합하거나 진위를 판정하지 않는다. 구조적으로 유효한 상충은 completeness나 consistency 보장의 실패가 아니다.

## CON-003.6 Canon과 다른 개념의 분리

Canon은 World의 transaction, Revision, export, access 또는 publication boundary를 대체하지 않는다. Canon은 세계 안에서 일어난 Event·CompositeEvent·Process, 원자료인 Source·Corpus 또는 사람이 읽는 authored prose인 Narrative와 동일한 개념이 아니다.

## CON-003.7 canonical content와 파생 표현의 분리

Subject, Process, State, Duration, Timeline, chronology와 시각적 표현처럼 canonical Event·Relation에서 계산되거나 해석되는 결과는 그 근거와 구분한다. Canon 변경을 이유로 파생 결과를 세계의 새 canonical entity로 승격하지 않는다.

## CON-003.8 표현과 출판이 의미를 지배하지 않음

성능, 저장 방식, 작성 도구, 공개 화면 또는 출판 여부의 편의를 위해 Canon의 의미, Event identity 또는 membership cardinality를 바꾸지 않는다.
