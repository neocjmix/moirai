## A — 그림 유지와 읽기 재사용

- loading/error에서 성공한 기존 그림을 유지하고 현재 camera transform을 적용한다.
- 점/영역만 먼저 교체하던 2단계 요청을 전체 artifact class 단일 요청으로 바꾼다.
- 완전한 응답은 한 번에 반영하여 ID가 같은 SVG를 유지한다. 부분 응답은 ID 병합,
  기존 선택·주변 자료 유지 및 visible cell 상한을 적용한다.
- loader별 cache는 query/source/revision/frame/filter에 격리한다. bbox coverage,
  selection/neighbor/LOD/viewport 조건을 확인하며 truncated 응답을 완전한 coverage로 보지 않는다.
- LRU: 최대 8개 응답/8 MiB. 진행 요청 중복 제거, 동시 요청 상한 및 취소/오래된 결과 차단.
- 기존 y-band/overscan 규칙, 전체 World를 browser에 읽지 않는 경계를 유지한다.
- 종료: 느린/실패 응답에도 기존 요소가 사라지지 않음, 부분 응답이 연결선을 지우지 않음,
  cache hit·eviction·query 격리·빠른 왕복 검사 통과 및 production checkpoint.

## B — 경계와 배율

- 선택 Canon 전체 spatial metadata bounds를 기존 수평 합성 offset으로 합친다.
  현재 로딩된 요소로 경계를 추정하지 않는다. metadata가 불완전하면 제한을 강제하지 않는다.
- 사방 화면 반 개의 여유를 두고, 초과 drag에는 점증 저항을 적용한다.
- 손을 놓으면 짧게 경계로 복원한다. reduced-motion이면 즉시 복원한다.
- 가로/세로 독립 배율을 유지하며 각 축 전체 데이터가 들어오는 배율보다 과도하게
  축소하지 않는다. 0폭/단일 사건은 최소 표시 span을 사용한다.
- 외곽으로 벗어난 URL 복원은 선택 사건 중심, 없으면 전체 범위로 복구한다.
  정상 범위 URL, pinch 중심, 실제 연대 간격은 유지한다.
- 복귀 버튼·minimap·공백 압축·새 renderer는 추가하지 않는다.
- 종료: 무한 외곽 이동/축소 방지, 저항과 복원, mobile pinch/restore 및 production checkpoint.
