# CON-005 — 비공개 작성과 공개 출판의 경계

## CON-005.1 명시적 출판

저장과 출판은 서로 다른 행위다. Lachesis에 존재한다는 이유만으로 콘텐츠가 공개되어서는 안 된다.

## CON-005.2 공개 표면

Atropos만이 실질적인 공개 사용자 서비스다. Clotho와 Lachesis의 작성·관리 기능은 공개 독자 서비스의 일부가 아니다.

## CON-005.3 작성 정보 보호

초안, 내부 검증 결과, LLM 작업 과정, 비공개 출처와 운영 정보가 의도하지 않게 Atropos에 노출되어서는 안 된다.

## CON-005.4 출판자 권한

무엇을 언제 공개하고 수정하거나 철회할지는 인간 출판자가 결정한다.

## CON-005.5 공개본의 일관성

독자는 의도적으로 출판된 일관된 내용을 제공받아야 한다. 진행 중인 내부 변경이 공개본을 우발적으로 변화시켜서는 안 된다.
