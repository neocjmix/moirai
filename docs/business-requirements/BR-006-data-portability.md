# BR-006 — 데이터 이동성과 장기 보존

관련 헌법: [CON-007](../constitution/CON-007-data-sovereignty.md)

## BR-006.1 전체 내보내기

사용자는 자신의 세계와 그 의미를 재구성하는 데 필요한 데이터를 내보낼 수 있어야 한다.

## BR-006.2 다시 가져오기

내보낸 세계를 동일하거나 후속 버전의 시스템으로 다시 가져올 수 있어야 한다.

## BR-006.3 백업과 복구

사용자는 데이터 손실에 대비해 세계를 백업하고 복구할 수 있어야 한다.

## BR-006.4 제품 교체 가능성

특정 LLM, 스킬, 공개 UI 또는 호스팅 환경을 교체해도 세계의 핵심 의미를 보존할 수 있어야 한다.

## BR-006.5 이전 호환성

Moirai가 발전해도 이전에 작성된 세계를 읽고 필요한 경우 새로운 형식으로 이전할 수 있어야 한다.
