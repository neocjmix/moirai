# BR-007 — 콘텐츠 출판 생명주기

관련 헌법: [CON-005](../constitution/CON-005-publication-boundary.md)

## BR-007.1 자동 출판

Clotho를 통해 성공적으로 반영된 세계 내용에는 별도의 draft, 출판 대기 또는 승인 완료 후 미출판 상태가 없어야 하며 현재 Publication의 내용이 되어야 한다. 이 요구사항은 공개 제공 시간에 관한 SLA를 의미하지 않는다.

## BR-007.2 현재 공개본

운영자와 독자는 현재 Atropos가 제공하는 공개 상태가 무엇인지 확인할 수 있어야 한다.

## BR-007.3 일관된 반영

하나의 의미 있는 변경이 일부만 공개되어 세계를 불완전하게 보여서는 안 된다.

## BR-007.4 정정

성공적으로 반영된 정정은 현재 공개본에도 자동으로 반영되어야 한다.

## BR-007.5 철회

잘못되었거나 더 이상 제공하지 않을 콘텐츠를 현재 공개 상태에서 철회할 수 있어야 한다.

## BR-007.6 내부 정보 보호

LLM 작업 과정, 내부 검증 결과와 운영 정보는 자동 출판 대상이 아니며 Atropos에 노출되어서는 안 된다.

## BR-007.7 후속 확장

draft, 선택적 출판, 사전 검토와 과거 공개본 열람은 1차 구현 범위에 포함하지 않는다.
