# CON-005 — 운영 경계와 자동 출판

## CON-005.1 1차 구현의 자동 출판

Clotho를 통해 성공적으로 반영된 세계 내용은 Lachesis에 보존되며 현재 Publication의 내용이 된다. 별도의 draft, 출판 대기 또는 승인 완료 후 미출판 같은 비공개 중간 상태를 관리하지 않는다.

이는 Atropos의 실제 제공 지연 시간에 관한 SLA가 아니라 콘텐츠의 논리적 생명주기에 관한 원칙이다.

## CON-005.2 공개 표면

Atropos만이 실질적인 공개 사용자 서비스다. Clotho와 Lachesis의 작성·관리 인터페이스는 공개 독자 서비스의 일부가 아니다.

## CON-005.3 세계 내용과 내부 정보의 경계

Event, Relation, Narrative와 Canon 간 대응 같은 세계 내용은 자동 출판 대상이다. LLM 작업 과정, 내부 검증 결과, 운영 로그, 비공개 자격 정보와 시스템 내부 정보는 Atropos에 노출되어서는 안 된다.

## CON-005.4 정정과 철회

인간은 공개된 세계 내용을 정정하거나 철회할 수 있어야 한다. 성공적으로 반영된 정정은 현재 공개 상태에도 자동으로 반영된다.

## CON-005.5 공개 상태의 일관성

Atropos가 제공하는 각 시점의 공개본은 하나의 의미 있는 변경이 일부만 적용된 불완전한 상태여서는 안 된다. 최신 상태를 제공하기까지의 전파 시간은 이후 기술 명세에서 다룬다.

## CON-005.6 후속 출판 흐름

draft, 선택적 출판, 사전 검토와 과거 공개본 열람은 후속 확장으로 추가할 수 있다. 이러한 확장은 World, Canon, Event, Relation과 Narrative의 의미를 변경하지 않아야 한다.
